Readwide APK open-source notices: libarchive-android and native codecs
========================================================================

This file is packaged inside the Readwide APK because the source module at
third_party/libarchive-android builds the native libarchive-jni.so library.
The pinned libarchive-android wrapper commit is
3a592be028c7be41847f667570bd343c0010bd9d. Readwide advances its libarchive
source baseline to the official v3.8.9 tag while retaining the wrapper's
codec revisions:

  libarchive  27cbc7827172698143e440801fc0ba39ccb4f1f5 (3.8.9)
  bzip2       6a8690fc8d26c815e798c588f796eabe9d684cf0
  XZ Utils    4b73f2ec19a99ef465282fbce633e8deb33691b3
  LZ4         ebb370ca83af193212df4dcbadcc5d87bc0de2f0
  Zstandard   f8745da6ff1ad1e7bab384bd1f9d742439278e99
  Mbed TLS    068ff080b369adfac81509f9b57b2afabaf82dc5

The Android NDK platform libz is also linked. The source tree contains no
prebuilt AAR or shared library. The notices below reproduce the applicable
upstream license/copyright terms for binary distribution.
