Readwide는 TXT, Markdown, PDF, EPUB, Word 계열 문서, HWP/HWPX, 이미지, 만화 압축파일, 일반 압축파일 흐름을 다루는 로컬 우선 안드로이드 리더 및 파일 브라우저입니다.

로컬 파일 읽기, 읽기 이력 검색이 되는 최근 파일, 북마크, 폴더 바로가기, 파일 검색 및 형식 필터, 문서 내 텍스트 검색(PDF 내부 찾기 포함), 압축파일 탐색, 압축파일 내부 이미지 보기, 다중 선택, 복사/이동/삭제/압축 해제/압축 생성 대기열, 그리고 취침 타이머·일시정지/재개·화면 위에 떠 있는 컨트롤을 갖춘 음성 읽기를 지원합니다.

TXT는 정확한 원문 페이지 모델을 유지하고, Markdown은 WebView 렌더링 기반 시각 페이지 모델을 사용합니다. PDF 문서 내 찾기는 디지털(텍스트 기반) PDF에서 동작하며, 스캔본이나 이미지 전용 PDF는 검색되지 않고 OCR은 포함하지 않습니다. HWP/HWPX는 Apache-2.0 Java 라이브러리를 통한 텍스트 우선 읽기 전용 지원이며, 한컴과 동일한 레이아웃 렌더링이나 편집 기능은 아닙니다. RAR/CBR은 읽기 전용이며 제한적입니다. 일부 압축파일은 열리지 않을 수 있고, 전체 RAR 호환은 보장되지 않습니다.

기본 빌드는 인터넷 권한을 요청하지 않으며 광고, 분석, 원격 텔레메트리 SDK, Firebase, Google Play Services, 계정 시스템, 클라우드 동기화, 인앱 업데이트 확인 기능, 개발자 운영 업로드 서버를 포함하지 않습니다. 안드로이드 자동 백업도 비활성화되어 있습니다. 넓은 파일 접근 권한은 사용자가 선택한 로컬 폴더와 파일을 읽고 관리하기 위해 사용됩니다. 다른 앱에서 Readwide로 연 파일은 파일명 정리, 경로 검증, 단일 파일 2GB 제한을 거쳐 앱 전용 캐시로 복사되며, JSON 백업 가져오기는 최대 256MB까지 허용합니다.

Readwide는 Android applicationId로 com.readwide.manager를 사용하며, 더 오래된 TextView Reader 빌드는 com.textview.reader를 사용해 별도의 앱으로 설치됩니다. F-Droid 빌드는 F-Droid가 서명하므로 다른 서명 키를 사용하는 GitHub의 Readwide APK 위에 덮어쓰기로 업데이트되지 않습니다. 빌드를 옮기려면 이전 빌드에서 JSON 백업을 내보낸 뒤 새 빌드를 설치하고 백업을 가져와 북마크, 읽기 위치, 테마, 설정을 복원하세요.
