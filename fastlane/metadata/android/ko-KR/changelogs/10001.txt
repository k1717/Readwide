Readwide 1.0.1

- 없는 파일의 북마크는 테마에 맞는 파일 없음 표시와 안내 창을 보여주며, 나중에 다시 연결할 수 있도록 유지합니다.
- 백업 가져오기는 현재 기기에 실제 존재하는 last directory, recent folders, folder shortcuts만 복원합니다.
- TXT 북마크의 Page X/Y 값은 현재 기기 레이아웃에서 다시 계산되며, 문자 위치/줄/앵커/파일 fingerprint가 안정적인 위치 기준으로 유지됩니다.
- 확대된 PDF 페이지에서 관성 fling 이동을 지원합니다.
- 이미지뷰어 가로모드는 Android 3버튼 내비게이션 safe area를 반영합니다.
- 이미지뷰어 기본 맞춤은 자동입니다. 가로로 긴 이미지는 가로폭에, 세로로 긴 이미지는 세로폭에 맞춰 엽니다.
- 이미지뷰어는 확대 후 맞춤 보기로 돌아와도 detail/original 디코딩 결과를 유지합니다.
- 압축파일 내부 이미지의 최근/저장 위치 재진입 경로를 보강했습니다.
- 오래된 ZIP, ALZ, EGG 내부 파일명에 대해 raw name byte가 있는 경우 더 넓은 best-effort 인코딩 감지를 사용합니다.
- 암호 압축파일 이미지 미리보기는 선택 이미지 우선 lazy 추출을 사용하고, sensitive cache 재사용 전 현재 비밀번호를 검증합니다.
- 지원되는 ALZ/EGG 추출 경로는 가능한 경우 streaming 처리해 peak memory 사용을 줄입니다.
- 압축파일 오류 UI는 비밀번호 필요, 잘못된 비밀번호, 미지원 기능, 손상된 파일, 일반 실패를 더 명확히 구분합니다.
- GitHub/F-Droid 공개 문서를 Readwide 1.0.1 릴리스 기준으로 정리했습니다.
