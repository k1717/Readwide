Readwide 1.0.1

- Missing bookmark target files stay visible with a themed missing-file label and explanation dialog.
- Backup import restores last directory, recent folders, and folder shortcuts only when those directories exist on the current device.
- TXT bookmark Page X/Y values are refreshed under the current device layout while character position, line, anchor text, and file fingerprint remain the stable target.
- Zoomed PDF pages support inertial fling panning.
- Image viewer landscape mode respects Android 3-button navigation safe areas.
- Image viewer default fit is adaptive: wide images fit to width and tall images fit to height.
- Image viewer keeps detail/original decode after returning from zoom to fit view.
- Archive-backed image viewer recent/saved-position reopen paths were hardened.
- Legacy ZIP, ALZ, and EGG entry names use broader best-effort filename encoding detection where raw name bytes are available.
- Password-protected archive image preview uses selected-image-first lazy extraction and validates sensitive cache reuse with the current password.
- ALZ/EGG supported extraction paths stream to output where possible to reduce peak memory use.
- Archive error UI better separates password-required, bad-password, unsupported-feature, corrupt-archive, and generic failures while keeping compatibility claims conservative.
- Public GitHub/F-Droid documentation was cleaned for the Readwide 1.0.1 release line.
