Readwide is a local-first Android reader and file browser for TXT, PDF, EPUB, Word documents, images, comic archives, and common archive workflows.

It supports TXT/PDF/EPUB/Word reading, image viewing, archive image sequences, recent files, folder/search controls, multi-select file operations, copy/move/delete/extract/compress queues, and progress UI.

The default build does not request the INTERNET permission and does not include ads, analytics, an account system, cloud sync, telemetry, or a developer-operated upload backend. Android Auto Backup is disabled. Broad file access is used for local file browsing and management of user-selected folders and files.

Readwide 1.0.1 is the current public package. The Android applicationId remains com.textview.reader for update compatibility with earlier compatible builds when signed with the same key.
